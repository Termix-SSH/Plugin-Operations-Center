## Overview

Operations Center is where you run and watch the actions other plugins offer. Docker, Services, Wake-on-LAN, Kubernetes and the rest declare what they can do, and this plugin turns that into one place to run them on one host or hundreds, approve what needs a person, see what changed and spot hosts that drifted. It also adds a page per host with every tool in one tab, and tables across all your hosts.

Read the [docs](https://docs.termix.site/plugins/operations-center) to set it up and use it.

<br />

## Features

- Run any action any plugin offers, with a form, a dry run and the result
- Roll an action out across many hosts with a canary, batches and a failure limit
- One history of every action, who ran it, from where and what happened
- Approve or reject what the assistant, MCP or a rule says needs a person
- Rules for what needs approval, by risk, plugin, action, where it came from and host tag
- Drift checks that watch hosts stay the way they should, with an optional fix
- A page per host with every tool, status tiles and recent changes in one tab
- Tables across every host, such as all containers or services, with bulk actions
- An MCP server so outside AI tools can use Termix actions with an API key
- A Needs attention card on the dashboard
- Status tiles and one click action buttons for the homepage
